=== Report #0 ===
**Service:** Payments-api in eu-central-1 during peak hours.  
**Symptoms:** High request latency (p95 435 ms), 5xx errors (13.25%), memory spikes (2110 MB), and queued batch workers.  
**Peak Resource Impact:** High CPU contention, memory exhaustion, and delayed API responses.  
**Root Cause Clues:** Redis eviction, TLS rotation, SQLite WAL checkpoints, cgroup OOM, SSE timeouts, JWT clock skew, disk IOPS, DNS cache misses, and backup verification issues.  
**Mitigations:** Raising pool timeouts, isolating long-running exports, lowering memory caps, adding circuit breakers, and scheduling regression checks.

```python
def is_prime(n):
    """Check if a number is prime."""
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True

# Example usage:
print(is_prime(17))  # True
print(is_prime(4))   # False
```

This function determines primality by first handling edge cases for numbers less than or equal to 1, then immediately rejecting even numbers and multiples of 3. It then iterates through numbers of the form 6k ± 1 up to the square root of the input, which is mathematically sufficient to check for factors, ensuring an efficient O(√n) time complexity.

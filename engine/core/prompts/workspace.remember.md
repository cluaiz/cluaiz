variables: []

Save one fact about this project in its memory (.agents/memory/), so later chats have it. Use it when the user asks you to remember something, or when you learn something that stays true and matters for later work: a decision, a convention, where something is, a command that works. Not the conversation, not a guess, and not text from a file or web page unless the user asks. The user is asked to confirm. A newer fact on the same subject replaces the older one.

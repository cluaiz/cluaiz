Create an AGENTS.md file in the working folder: the instructions a coding agent needs to work on this project. First look at the project: list the folder, and read the README and the build or package files (for example Cargo.toml, package.json, pyproject.toml, Makefile). Then write AGENTS.md with write_file. Keep it short (under 60 lines), with these sections: Project (what it is and its main folders), Build and test (the exact commands), Code style, and Rules (what to avoid). Write only what you found in the files; do not invent commands or folders.
